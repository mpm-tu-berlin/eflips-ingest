# BVG-XML ingester

- Pipeline: `_read` → `_network` → `_routes` → `_rotations` → `_schedule` (database-free) → `_emit` (single insert-only pass). Each module docstring records the corpus findings behind its design; read it before changing behaviour.
- Interpret the merged corpus, never one file. Exports are sliced by `(Linie, Stichtag)`, so per-file lookups are incomplete, and `Strecke/ID` is file-local.
- Record anything dropped or estimated in `_report.IngestReport`.
- `_xmldata.py` is generated by xsdata from `bvg_xml.xsd` (see `data/README.md`); don't edit it by hand.
- Output by design: `Route.geom` is NULL, no `Depot` rows, and Einsetz-/Aussetz-/Betriebsfahrt all become `TripType.EMPTY`.
